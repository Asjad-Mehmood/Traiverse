# Traverse Pro 1.0.0

The first release of Traverse Pro: close and adjust a traverse from the field book, on your own
computer, with no internet connection.

- **Load and list.** Type the field book one set-up per row, load a CSV or TXT file, or add
  stations by clicking on the plan. Side shots hang off any set-up.
- **Close and adjust.** Closed loops, closed links and open traverses, adjusted by Compass
  (Bowditch), Transit or least squares, with angular, linear and level checks against the
  tolerance of the traverse class.
- **Report.** A printable report of the set-up, the field book, the closure, the checks and the
  adjusted coordinates. Print it, or choose *Microsoft Print to PDF*.
- **Updates itself.** Each time it opens, the program checks for a newer version.

Download **TraversePro-Setup.exe** below and run it. It installs for your user only and does not
need administrator rights. If SmartScreen says *Windows protected your PC*, press **More info**,
then **Run anyway**.
