# Traverse & Level 2.3.0

**What's new:** help and support, built in.

- **Help** (the **?** at the top right): the user manual, What's new, **Report a problem** (the
  contact form opens with the version filled in), the **error log** and the **open-source
  licences**. Pages open in your browser.
- **A clear message when something goes wrong.** If the program stops because of an error, it
  says so and where the error log is, instead of just closing.
- **The program's icon in the window's title bar** and on the taskbar button. It was blank.
- **A start screen** with the icon and name shows straight away while the program opens.
- **Signed in already.** Opened from a desktop shortcut or the Start menu, it signs in with the
  Survey Toolkit's account on this PC, once, if there is one.
- Windows' list of programs shows the publisher (**SurveyX Digital**), the website and the size.

**What hasn't changed:** adjustments, the field book, least squares, the Qatar National Grid and
your saved jobs work exactly as in 2.2.2.
